# 2026-1: Hyland Desktop Host
## Description
Hyland Desktop Host for Windows versions < 25.1.1 runs a privileged service from a folder with weak permissions. A local authenticated user can exploit this to escalate privileges to `LOCAL SERVICE`.
## CVE
CVE-2026-110359
## CVSS
Base score: 7.8 (CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H)
## Details
Hyland Desktop Host installs to the `C:\ProgramData\Hyland\DesktopHost\bin` folder, where non-privileged users can write new files. The `Hyland Desktop Host Gateway` service (`Hyland.DesktopHost.Gateway.exe`), which runs as `LOCAL SERVICE`, will attempt to load the non-existent `cryptbase.dll` DLL from this location on start. A malicious DLL with that name can be placed in the folder, which will then be loaded and executed by the service on subsequent system boots.
